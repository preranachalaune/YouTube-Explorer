# YouTube Explorer

A responsive YouTube video search application built with React, Node.js, Express, and RapidAPI.

## Features

- Search YouTube videos using keywords
- Display video thumbnails, titles, channels, and durations
- Load more videos using cursor-based pagination
- Loading indicators
- Error handling
- Responsive user interface

## Technologies Used

### Frontend
- React
- JavaScript
- CSS
- Vite

### Backend
- Node.js
- Express.js
- RapidAPI
